# Calculator (вариант 13 — логарифмический)

Программа-калькулятор для вычисления логарифмов.

## Поддерживаемые операции

| Операция | Описание | Операндов |
|----------|----------|-----------|
| `ln`     | Натуральный логарифм `ln(x)` | 1 |
| `log`    | Логарифм `log_y(x)` по основанию `y` | 2 |

## Сборка (Debian/Linux)

```bash
sudo apt install build-essential
make
